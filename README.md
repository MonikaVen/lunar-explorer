# Lunar Explorer — lunar terrain and return flight

Open `Lunar-Explorer-Standalone.html` (all assets embedded), or `index.html` with `game.js`, `style.css`, and the `assets/` directory together.

## Surface expedition
Exit the lander (E), board the rover (E), use arrows or A/D to drive, and collect all three Moon rock samples on foot (E). Jump with Space/W/Up to land on the crater target; use E to dig soil. Return to the parked rover, then the lander and press E to deliver samples.
